# 操作记录

> **维护对象**：任何 AI 助手和人类读者。
> **目的**：记录每一次对代码或文档有实际变更的事项，防止上下文在长会话或跨会话中丢失。

## 维护规范

1. **每个条目必须有状态**：🟢 已完成 / 🟡 进行中 / 🔴 废弃
2. **废弃条目处理**：确认无历史参考价值后删除；有保留价值的（如设计方向曾被尝试后放弃）改为废弃态并注明原因
3. **新条目追加**：按时间顺序，新增在同 Phase 节末尾或创建新节
4. **内容底线**：做什么 + 为什么 + 结果。不记录纯讨论/调研，只记录对代码或文档产生了实际变更的事项
5. **时效性**：进行中的条目超过 7 天无更新，主动询问是否仍有效或标记废弃
